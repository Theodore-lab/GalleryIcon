# GalleryIcon Specification

Goal:
Allow a user to select any image from device storage and use it as the app icon.

Requirements:

- Select image from gallery
- Select image from file manager
- Preview icon
- Change icon unlimited times
- No ads
- No purchases
- Offline only

Icon Behavior:

- Image should fill the icon area as much as Android permits
- Optional square crop
- Optional circle crop
- Optional no-crop mode
- Preserve image quality

Launcher:

- Replace previous shortcut automatically
- Open the same app when tapped
